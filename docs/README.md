# 장비 관리 프로그램 (UL Project)

연구실 평면도 위에 테이블·선반·카트를 배치하고, 각 기구에 장비 정보(이름, UL 번호, Global 번호, 사진, 메모)를 등록·검색할 수 있는 Windows 데스크톱 앱입니다.

상단에서 **배치 / 편집 / 검색** 세 가지 모드를 전환하며 사용합니다.

![배치 모드 화면](docs/images/place-mode.png)

---

## 1. 배치 모드

기구를 생성하고 위치를 잡는 모드입니다. 테이블, 선반, 카트를 만들고 **이동·크기 조절·회전**할 수 있습니다.

좌측 팔레트의 **테이블 / 선반 / 카트**를 맵 영역으로 드래그해서 떨어뜨리면 배치됩니다.

![기구 배치](docs/images/place.png)

배치된 기구를 **우클릭**하면 다음 작업을 할 수 있습니다.

- **90도 회전** — 기구를 90도 단위로 돌립니다
- **크기 조절** — 가로·세로 크기를 입력해 조절합니다
- **삭제** — 기구를 지웁니다

![우클릭 메뉴](docs/images/context-menu.png)

> 기구를 드래그하면 이동, 모서리를 끌면 크기 조절도 됩니다.

---

## 2. 편집 모드

기구의 **장비 정보만 수정**하는 모드입니다. 이동·크기 조절은 비활성화되어, 실수로 배치가 바뀌는 것을 막아줍니다.

상단 **편집** 버튼을 누른 뒤, 정보를 입력할 기구를 클릭합니다.

![편집 모드](docs/images/edit-mode.png)

기구를 클릭하면 장비 편집 창이 열립니다. 기구 이름과 팀을 정하고, **장비 추가** 버튼으로 장비 행을 늘립니다. (기구 하나당 장비 최대 100개)

![장비 행 추가](docs/images/edit-add-row.png)

각 장비마다 **이름 · 장비구분 · UL 번호 · Global 번호 · 비고**를 입력합니다. 행을 선택해 복사/붙여넣기하거나 여러 행을 한 번에 삭제할 수도 있습니다.

![장비 정보 입력](docs/images/edit-filled.png)

**사진** 칸의 버튼을 누르면 장비 사진을 등록/확인할 수 있습니다. 등록된 사진이 없으면 "등록된 사진이 없습니다"로 표시되고, **사진 추가**로 이미지를 넣을 수 있습니다.

![장비 사진 보기](docs/images/photo-view.png)

---

## 3. 검색 모드

등록된 모든 장비를 한 번에 찾는 모드입니다. 상단 **검색** 버튼을 누르면 검색 창이 열립니다.

검색 기준(**Name / UL / Global**)을 고르고 검색어를 입력합니다.

![장비 검색](docs/images/search-empty.png)

검색하면 전체 맵에서 일치하는 장비를 **유사한 결과 순서**로 보여줍니다. 각 결과에는 장비 이름, 속한 기구와 맵, UL/Global 번호가 함께 표시됩니다. 결과를 클릭하면 해당 맵으로 이동해 그 기구가 강조 표시됩니다.

![검색 결과](docs/images/search-result.png)

---

## 그 밖의 기능

- **맵(탭) 관리** — 상단 `+` / `−` 버튼으로 맵을 추가·삭제하고, 탭을 더블클릭해 이름을 바꿉니다. (Energy room, Center, ITAV 등 구역별로 나눠 관리)
- **단축키** — 선택한 기구 라벨 복사 `Ctrl + C`, 붙여넣기 `Ctrl + V`
- **자동 저장** — 배치 내용은 자동 저장되어 다음 실행 시 그대로 복원됩니다
- **전체 초기화** — `모든 배치 처음으로 되돌리기` 버튼으로 초기 상태로 리셋

---

## 실행 방법

Windows에서 .NET 10 SDK 설치 후:

```bash
dotnet run --project UL_project
```

또는 Visual Studio에서 `UL_project.slnx`를 열어 실행합니다.
